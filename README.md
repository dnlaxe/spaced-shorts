# YouTube Shorts Spaced Repetition

Portfolio project demonstrating frontend-focused development with React and TypeScript.

A learning tool that uses YouTube Shorts with spaced repetition:

- Paste a YouTube Shorts link and study it later
- Rate your recall after watching
- A spaced repetition system determines when it reappears
- Organize content into playlists

## Features

- Playlist management (create, rename, delete)
- Add Shorts via URL
- Study mode with one short at a time
- Difficulty rating to drive review flow
- Client-side state management with real interactions
- Routing between playlists and study views

## Tech Stack

- **Frontend:** React 19, TypeScript
- **Build:** Vite
- **Routing:** React Router
- **Styling:** Tailwind
